# Drama 3 voice files (optional; docs/DRAMA3.md, "Fast server"): the packages drama-tensorfold's tools/zig/drama_voice.py needs to
# run sglang-omni's Fish reference encoder (sgl-project/sglang-omni @ ab095ef9), on top of the studio's TTS venv and its CUDA torch.
#
# Install into a separate venv that sees the TTS venv's packages through a .pth file (the TTS venv itself stays untouched):
#   "$STUDIO_TTS_PY" -m venv "$STUDIO_HOME/envs/drama3-voice"
#   SP=$("$STUDIO_HOME/envs/drama3-voice/bin/python" -c 'import sysconfig; print(sysconfig.get_paths()["purelib"])')
#   "$STUDIO_TTS_PY" -c 'import sysconfig; print(sysconfig.get_paths()["purelib"])' > "$SP/zz_tts_env_overlay.pth"
#   "$STUDIO_HOME/envs/drama3-voice/bin/pip" install --no-deps -r requirements/drama3-voice.txt
#
# --no-deps is required: every dependency is listed and pinned below. Above all, descript-audiotools and descript-audio-codec must be
# installed WITHOUT their dependencies: with them, pip resolves a torch of its own and older pins, which can replace or shadow the
# TTS venv's CUDA build of torch. sglang and transformers are pinned to the versions sglang-omni ab095ef9 expects; this venv's copies shadow the TTS
# venv's without changing it. Everything else they import (numpy, protobuf, PyYAML, Pygments, decorator, ...) comes from the TTS venv.
# Tested on a DGX Spark (aarch64, Python 3.12, torch 2.10 + CUDA 13.0 from the TTS venv).
#
